# Quantumult X PNG brand icons

All images in this directory are 108×108 PNG with alpha transparency.

- SpaceXAI: 2026 mark rendered without white background from existing sourced SpaceXAI vector-style artwork; it is an adaptation, not a direct official image file.
- Google G: Google's officially released 2025 gradient-G visual, sourced from the user's previously stored google.png brand image. [Google's own design announcement](https://blog.google/company-news/inside-google/company-announcements/gradient-g-logo-design/).
- Perplexity: teal logomark adapted from existing user repository asset (backgroundless).
- Other files remain intact. Trademarks belong to their owners. Use subject to their brand guidelines.
